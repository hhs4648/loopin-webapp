# 배포하지 않는 원본 · 백업

여기 있는 파일은 **앱에 실려 나가지 않습니다.** Vite는 `public/`만 그대로 복사하므로,
이 폴더는 빌드 결과물(`dist/`)에 들어가지 않습니다.

## 왜 옮겼나

`public/assets`에 165개 파일이 있었고 **전부 사용자에게 배포됐습니다.** 그중 70개
39.4 MB는 코드가 한 번도 참조하지 않는 것이었습니다 — Figma 원본(한글 파일명),
`-source`, `.bak-*`, `.before-extend`, 그리고 쓰지 않는 `.wav` 8개.

```
옮기기 전  public/assets  86.7 MB
옮긴 뒤    public/assets  46 MB      (dist 84 MB → 47 MB)
```

지우지 않고 옮긴 이유: 이 저장소는 git 저장소가 아니라 되돌릴 수단이 없습니다.
필요하면 `public/assets/`로 다시 옮기면 그대로 살아납니다.

## 판정 기준

`src/`, `public/legal/`, `index.html`을 통째로 읽어 파일명이 한 번도 나오지 않는 것만
골랐습니다. 경로를 문자열로 조립하는 곳(`castle-learning.ts`)도 파일명 자체는 리터럴이라
검사에 걸립니다. 옮긴 뒤 참조 검사와 빌드를 다시 돌려 깨진 곳이 없는 것을 확인했습니다.

## 여기 넣으면 안 되는 것

**코드가 참조하는 파일.** 옮기기 전에 반드시 파일명으로 `src/` 전체를 검색하세요.
`<img src="/assets/…">`처럼 큰따옴표로 쓰는 자리가 있어서, 작은따옴표만 찾으면 놓칩니다.
